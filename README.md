# Классификация текстов методом наивного Байеса

Учебный проект: реализация и сравнение двух вероятностных алгоритмов для классификации текстов на пяти компьютерных тематических категориях корпуса **20 Newsgroups**.

## Что реализовано

- Разделение документов каждого класса на обучающую (первые 80%) и тестовую (последние 20%) части.
- Предобработка текстов: перевод в нижний регистр и выделение последовательностей английских букв.
- Реализация **Multinomial Naive Bayes** и **Bernoulli Naive Bayes** через подсчеты и логарифмические вероятности, без использования готовых классификаторов scikit-learn.
- Сглаживание Лапласа; вычисление Precision, Recall, F1 по классам и Macro F1.
- Оптимизация Bernoulli-классификации: базовый логарифмический скор для отсутствующих признаков и поправки для присутствующих слов.

## Результаты исходного эксперимента

| Модель | Macro F1 |
|---|---:|
| Multinomial Naive Bayes | 0,6349 |
| Bernoulli Naive Bayes | **0,7203** |

Лучший результат в исходном эксперименте — Bernoulli Naive Bayes. Метрики воспроизведены из учебного отчета и не пересчитывались при сборке репозитория.

## Структура

- `scripts/NLP_Bayes.py` — полный эксперимент, от загрузки корпуса до оценки метрик.
- `requirements.txt` — библиотека, необходимая для загрузки датасета.


Первый запуск требует подключения к интернету для скачивания корпуса через `fetch_20newsgroups`. Подготовка и вычисления выполняются локально.
